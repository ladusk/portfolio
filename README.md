# Portfólio - Hendrick Oliveira

Este projeto foi desenvolvido como atividade final do 4º Bimestre. É um portfólio responsivo construído do zero com HTML5, CSS3, JavaScript e Bootstrap, focado em demonstrar domínio de interfaces e de dados no lado do cliente.

# Automação de Formulário (Etapa 2.2)
Para atender ao requisito de automação e notificação real de formulário, escolhi utilizar a ferramenta EmailJS. 
**Justificativa da escolha:** O EmailJS permite o envio de e-mails diretamente do frontend (Client-side) através de JavaScript, eliminando a necessidade de criar um backend ou servidor de e-mail. Ao preencher o formulário de contato, a mensagem é salva no LocalStorage e um e-mail real é enviado para a minha caixa de entrada.

# Como acessar o Painel Administrativo Oculto (CRUD)
Para validar as operações de Criar, Ler, Atualizar e Deletar mensagens, o sistema possui uma área restrita:
1. Acesse a página principal do portfólio.
2. Role até o final da página e clique no símbolo de copyright © no rodapé.
   (Alternativa: Pressione o atalho Ctrl + Shift + A no teclado).
3. Você será redirecionado para a página admin.html, onde poderá visualizar as 20 mensagens de teste injetadas automaticamente pelo sistema, além de editar ou excluir qualquer registro.

# Armazenamento Local (Etapa 2.1)
O sistema utiliza a API nativa localStorage do navegador para armazenar os dados em formato JSON. Na primeira visita, uma verificação é feita; se o armazenamento estiver vazio, 20 registros de teste são injetados automaticamente para facilitar a validação.
